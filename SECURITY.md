# Security Policy

Please do not report security issues in public issues or pull requests.

Report them privately to the maintainers of this repository, using GitHub's private vulnerability reporting
(the "Report a vulnerability" button in the Security tab of
https://github.com/palladium-coin/plm-electrumx).

For problems in the upstream ElectrumX code that are not specific to this fork, see also
https://github.com/spesmilo/electrum/blob/master/SECURITY.md
